# Title
Pomodoro Tomodachi

## Repository
https://github.com/blumou5/PFDA_FinalAssignment.git

## Description
This project is to aid students in maintaining their focus while they work/study. You'll be able to set a timer, and have a digital companion to interact with during break times.

## Features
- Clock / Timer
	- The clock will allow user input for study time and break time lengths. There will be a reset button, an option for preset times, pause/play timer, and sound effects for notifying the user of the clock's status.
- Companion / Friend
	- There will be a cute, customizable companion character that will have preset sprites that changed based on clock status or user interaction. (Modes: Study, sleep, silly, eating, dancing)
- Currency System
	- A currency system tied to the amount of minutes the user studies/works. Currency will save. The user will be able to buy food and furniture for the companion.
- Save / Reset System
  - The user will be able to save progress with their companion, but also be able to reset their progression at the click of a button (with an additional "Are you sure?" check in case of accidental misclicks.)

## Challenges
- Creating conditions/loops for the sprites to occur (sometimes randomly).
- Creating an interactible timer that also tracks the minutes.
- Creating interactible buttons for the user that trigger outputs.

## Outcomes
Ideal Outcome:
- A cute study companion that helps aid fellow students who tend to get distracted or work better with a friend to study/work with; and rewards longer study/work times.

Minimal Viable Outcome:
- A pomodoro timer for focusing on study/work (AT LEAST THE TIMER!)
